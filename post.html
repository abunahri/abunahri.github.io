Belajar HTML Dasar

Post Publish on 3 January 2026 by John Doe

HTML atau HyperText Markup Language adalah bahasa markup yang digunakan untuk membuat struktur sebuah halaman web. HTML merupakan dasar yang perlu dipahami sebelum belajar teknologi web lainnya seperti CSS dan JavaScript.

Dengan HTML, kita dapat membuat berbagai macam elemen pada halaman web seperti judul, paragraf, gambar, link, tabel, form, tombol, dan masih banyak lagi.

Apa Itu HTML?

HTML menggunakan tag untuk memberitahu browser bagaimana sebuah konten harus ditampilkan. Setiap tag memiliki fungsi tertentu.

Contohnya adalah tag <h1> untuk membuat judul dan tag <p> untuk membuat paragraf.

Struktur Dasar HTML

Berikut adalah contoh struktur dasar sebuah dokumen HTML:

<!doctype html>
            <html lang="en">
            <head>
                <meta charset="UTF-8">
                <title>Belajar HTML</title>
            </head>

            <body>
                <h1>Hello World</h1>
                <p>Saya sedang belajar HTML.</p>
            </body>
            </html>

Tag HTML yang Sering Digunakan

Beberapa tag HTML yang sering digunakan oleh pemula antara lain:

  • <h1> - <h6> untuk membuat heading
  • <p> untuk membuat paragraf
  • <a> untuk membuat link
  • <img> untuk menampilkan gambar
  • <ul> dan <ol> untuk membuat daftar
  • <table> untuk membuat tabel
  • <form> untuk membuat formulir

Kesimpulan

HTML merupakan dasar penting dalam pembuatan website. Setelah memahami HTML, kita dapat melanjutkan belajar CSS untuk mengatur tampilan dan JavaScript untuk menambahkan interaksi pada halaman web.

Semakin sering berlatih membuat halaman HTML sederhana, semakin mudah kita memahami bagaimana sebuah website dibangun.
